新维智能 NEWDIM 官网 —— 部署说明
==================================

一、文件说明
  index.html          网站首页（产品中心、品牌、联系方式等都在这个页面里，用 # 路由切换）
  s60.html            S60 3D 全屏展示页
  app.js / data.js    页面逻辑与产品数据
  styles.css          样式
  s60-3d.bundle.js    3D 展示脚本（已内含 three.js，不依赖外网）
  assets/             图片、品牌标识、3D 模型
    s60/s60-meshy.glb     3D 模型
    s60/s60-meshy.glb.js  同一模型的内嵌备份（服务器不认 .glb 或本地双击打开时自动使用）
  web.config          Windows IIS 主机配置（补充 .glb 类型、首页）
  .htaccess           Apache 主机配置

二、上传到网站
  1. 把 newdim-website 文件夹里的“全部文件”（包括以点开头的 .htaccess）上传到网站根目录，
     例如 public_html/、wwwroot/ 或 htdocs/，保持目录结构不变。
  2. 打开 https://你的域名/ 即可访问；3D 全屏页是 https://你的域名/s60.html
  3. 也可以放在子目录（例如 /site/），所有路径都是相对路径，无需修改。
  4. 文件名全部是英文小写，不受服务器编码影响。

三、本地查看
  直接双击 index.html 即可在浏览器里打开，图片和 3D 模型都能正常显示（建议用 Chrome / Edge）。

四、需要修改时
  · 联系电话、微信、邮箱、地址：app.js 文件开头的 CONTACT 部分
  · 产品和图片：在“官网素材”目录里修改后，按 官网/README.md 的步骤重新生成

五、浏览器要求
  Chrome / Edge / Firefox / Safari 近几年的版本、微信内置浏览器均可。
  3D 展示需要浏览器支持 WebGL；不支持时会自动显示产品照片。
